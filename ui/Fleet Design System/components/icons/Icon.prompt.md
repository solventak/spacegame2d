Interface affordances only — lock, chevron, radar, crosshair, x. Tactical meaning belongs to `Glyph`, not `Icon`.

```jsx
<Icon name="lock" size={12} />
<Icon name="chevron-right" style={{ color: 'var(--text-3)' }} />
```

The set is Lucide v0.544.0, inlined (source SVGs mirrored in `assets/icons/`). Icons inherit `currentColor`; `Icon.names` lists the available names.
