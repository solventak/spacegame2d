The in-world vocabulary: system types, fleet composition, stance, formation, target priority. Geometric primitives only — never a pictographic or illustrated icon.

```jsx
<Glyph name="relay" tone="friendly" size={16} />
<Glyph name="capital" /> <Glyph name="drone" />
```

Distinct from `Icon`, which is for interface affordances (lock, chevron, close) and comes from Lucide.
